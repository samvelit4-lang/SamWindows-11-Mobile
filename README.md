🖥️ SamWindows 11 Mobile

SamWindows 11 Mobile — проект Android-приложения, создающего среду Windows 11 на мобильных устройствах.

Наша цель — предоставить удобный интерфейс Windows 11 и возможность запускать Windows-программы непосредственно на Android.

✨ Основные возможности

- 🖥️ Интерфейс в стиле Windows 11.
- 📁 Проводник файлов.
- 🚀 Меню «Пуск».
- 🪟 Многозадачность и оконный режим.
- 🎮 Поддержка Windows-игр.
- ⌨️ Поддержка мыши и клавиатуры.
- 📱 Сенсорное управление.
- ⚡ Оптимизация производительности.

⚙️ Технологии

- Kotlin
- C / C++
- Wine
- Box64
- Vulkan
- Android SDK

📱 Совместимость

- Android
- ARM64
- Смартфоны и планшеты

🎯 Цель проекта

Создать собственную мобильную Windows-среду с возможностью запуска ".exe"-приложений, удобным интерфейсом и игровой оптимизацией.
