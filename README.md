# SamWindows 11 Mobile

Android-прототип мобильной оболочки в стиле Windows 11 от Samvel.

## Текущий этап: 0.1.0 Alpha
- Рабочий экран и панель задач.
- Простое меню «Пуск».
- Демонстрационные окна File Explorer, Settings и This PC.
- GitHub Actions для автоматической сборки debug APK.

## Важно
Это пока оболочка-прототип, а не Windows 11 и не среда запуска `.exe`.
Интеграция Wine/Box64, файловых контейнеров и графического ускорения ещё не реализована.
Запуск Windows-программ потребует отдельной ARM64-интеграции, проверки лицензий компонентов и тестирования совместимости.

## Сборка
Открой проект в Android Studio и собери `app` → `assembleDebug`.
Либо отправь файлы в GitHub: workflow **Android APK** соберёт APK и сохранит его в Artifacts.

Минимум: Android 8.0 (API 26), ARM64 рекомендуется для будущего слоя совместимости.
